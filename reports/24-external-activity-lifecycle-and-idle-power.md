# 24 外屏任务回切、空闲息屏与重插

2026-11-14（北京时间），popsicle / `OS4.0.6.0.XPBCNXM`。把普通应用回切、空闲息屏、解锁和重插放在同一次 D3 启用后的启动周期。在启用和停用 D3 时各重启一次。USB-C 口接显示器期间使用已和有线 boot ID 核对的无线 ADB，输出模式保持 2560×1440 @ 60 Hz。

## 真机结果

| 验证项 | 结果 | 证据 |
| --- | --- | --- |
| 独立应用落屏 | `PASS` | 从已确认正常的镜像切到独立显示，Display 2 仍为组 0、物理 `ON/ON`、`canHostTasks=true`。计算器实际在 Display 2，VRI `#498` 有 buffer，SF 读到 frame 6。外屏物理抓屏和用户观察均有画面。 |
| 普通应用切走、返回 | `PASS` | 时钟在同一外屏启动，移除本次时钟任务后，计算器以同一 ActivityRecord 和任务 ID 返回外屏。新 VRI `#526` 有 buffer、frame 2，并在外屏 HWC 图层表。用户确认返回后的计算器画面正常。 |
| 空闲息屏后解锁 | `FAIL` | 将临时延长的息屏时间恢复为 120 秒后，PMS 记录空闲超时。组 0 进入 Dozing，外屏迁入背屏组 1，DMS 与 SF 关闭外屏。用户唤醒解锁，内屏已亮，外屏仍 `OFF/OFF`，用户看到全黑且无状态栏。 |
| 独立模式重插 | `PARTIAL` | 拔线时计算器的同一任务短暂迁至 Display 0，随后 Activity 出现销毁超时并被移除。重插待选时外屏先分组 0，随后又迁到组 1 并关闭。用户从弹窗选「桌面」后，Display 2 启用且物理回到 `ON/ON`，仍在组 1。用户看到黑底和状态栏。次屏 HOME VRI `#648` 的 SF 快照为 `nothing to draw`。 |
| 外设输入 | `[待真机] NOT_RUN` | 现场无可用的外接鼠标、键盘或手柄。 |

空闲对照的设备时间为 17:00:53.530 超时、17:00:53.533 组 0 进入 Dozing、17:00:53.588 外屏迁组、17:00:53.603 下发外屏 `OFF`。解锁后仍保持同一次物理连接。此次复现了 [D11 第一次试验](23-stock-flutter-external-display-preflight.md) 的空闲时序，D11 复测中延长超时后那次迁组的触发源仍待定位。手动锁屏与空闲分开对照，当前可用的独立屏被空闲试验中断后未单独执行手动锁屏。

重插选「桌面」后，物理屏已亮。状态栏和 HOME 图层可见性对应两个渲染对象，可与前一段物理 `OFF/OFF` 的全黑区分。计算器的回切证明该轮外屏普通 Activity 能重建合成图层，原厂 Flutter 的安全入口和对应回切仍待验证。独立次屏 HOME 内容、从次屏 HOME 点击应用、完整自由窗口和物理高刷均未验收。

## 回退

写回镜像值 `1`，核对息屏时间已恢复到 120 秒，经有线 ADB 停用 D3 并重启。停用后模块状态及 Overlay 列表与基线一致，三个桌面资格值均恢复为 `false`，测试任务均已退出。经典模式仍生效，经典布局数据库主文件的 SHA-256 与测试前一致。内屏重新打开测试前所在的系统设置应用，原先的具体设置子页未恢复。无线 ADB 已验证与有线为同一启动。

用户重接外屏并确认镜像正常。无线复核外屏在组 0、物理 `ON/ON`、`canHostTasks=false`，SF 活动模式为 2560×1440 @ 60 Hz。内屏在组 0 且物理 `ON/ON`，背屏单独在组 1 且物理 `OFF/OFF`。
